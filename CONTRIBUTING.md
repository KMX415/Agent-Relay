# Contributing to Dead Drop

By intentionally submitting a contribution for inclusion in Dead Drop, you
agree to license it under the GNU Affero General Public License, version 3 only
(`AGPL-3.0-only`), as provided in [LICENSE](LICENSE). You retain your copyright;
this is not a copyright assignment or a grant of alternative licensing rights.

Submit only work you have the right to contribute under these terms. Identify
third-party material and retain its applicable license and attribution notices.
If employer or other rights-holder permission is required, obtain it before
submitting. Existing dependency licenses remain unchanged.

Read [AGENTS.md](AGENTS.md) and [docs/DEV-COORDINATION.md](docs/DEV-COORDINATION.md).
Use a feature branch, explain the problem and acceptance checks, and run
`npm test` for code changes. Keep toolkit code, mailbox storage, and target
project work distinct. Never include runtime state, credentials, worker
identities, private messages, or personal transcripts in a contribution.

If you operate a modified version that supports remote network interaction,
provide the prominent corresponding-source offer required by AGPLv3 section 13.
The offered source must match your version and include the material required
by the license; linking only to the unmodified upstream project is insufficient
when your modifications are absent there. Preserve licensing and attribution
notices when distributing copies.
